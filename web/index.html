      About draws

      Around a quarter of games end level, but a draw is almost never the single most likely result, so a model that only picks the favourite never calls one. Training with balanced class weights (the Raw setting) makes it call draws, and it catches a fair few, but it's wrong more often overall and its percentages run too high on draws. Calibration pulls the percentages back to reality, and in doing so it stops calling draws altogether. Flip between them above and watch the draw column in the table and the tiles.
